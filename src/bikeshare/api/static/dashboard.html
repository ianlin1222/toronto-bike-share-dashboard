How to read this dashboard

Generic Bike Share bicycle compatibility is assumed. No trip flows, rebalancing counts, routed distances, or model probabilities are inferred. Station plots use current-known coordinates. CSV exports contain only the displayed aggregate station statistics, not rider requests.

The browser dashboard complements the project’s Power BI assets; it is not a verified PBIX report.

Design reference: Claude Turned Bike Data Into a Video. Adapted as a manual dashboard without animation.
